SCOPE 2: Copilot Chat & Prompting (30 Questions)
1. What is the main purpose of GitHub Copilot Chat?

A. Compile code
B. Generate and explain code using natural language
C. Host applications
D. Run test suites
Answer: B

B. Clear and contextual prompts

Answer: B

# Certify Ready UI

Frontend package for the Certify Ready project.

For overall project documentation, architecture, question dump workflow, and full run instructions, see the root README at the repository root.

## UI-specific quick start

```powershell
npm install
npm run dev
```

Optional local API configuration in certify-ready-ui/.env:

```env
VITE_API_BASE_URL=http://localhost:5203
```

## Scripts

- npm run dev: start Vite dev server
- npm run build: create production build
- npm run preview: preview production build
- npm run lint: run ESLint
